每周占比

纵轴为该类型占当周全部上位的百分比 —— 整弹比赛变少时，上位数会一起下降，占比才看得出谁在真正扩张。
后几名占比低时会被压扁，可切对数轴（对数轴下 0 值不显示）。
说明：上位 = 数据源记录的入赏卡组（已按赛事人数过滤：不足 8 人的赛事整场排除，8~16 人的赛事只取前 4 名）。 某个类型在某周为 0 表示该周没有它的入赏记录；占比为 0 同理。
